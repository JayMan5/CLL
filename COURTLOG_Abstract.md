# COURTLOG

*Project Abstract — COUCH 2026*

COURTLOG is a competition-team prototype exploring how a registry could record physical-file custody, hearing events, and post-judgment execution activity alongside existing court systems. It is not a governmental entity, certified service, or approved public-sector deployment. Feature development is proceeding with synthetic/demo data; any future institutional pilot or live-data deployment is a separate decision requiring the relevant permissions and reviews.

The prototype has four workflow areas. Its installable QR/PWA shell records an authenticated custody check-in and presents a seven-day idle-custody prompt; that prompt does not prove a file is missing, and camera/printer acceptance on the intended phone remains pending. The hearing module records outcomes and currently applies a configured case-level review trigger at four recorded adjournments. That trigger is not a statutory determination or a per-party count; Law Lead approval remains pending. WhatsApp Cloud API code now supports consent-gated individual template sends, webhook verification, delivery-state updates, and inbound opt-out handling, but sending is disabled by default, blocked in demo mode, and has not been exercised against a configured Meta account or live recipient. The delay-risk screen shows experimental scores based on generated synthetic training scenarios and a heuristic fallback or prototype Logistic Regression artifact; there is no independent validation against real court outcomes, so the score is not a legal finding. The execution area tracks prototype workflow states and draft documents; its 90-day prompt and templates still require jurisdiction-specific legal review.

COURTLOG is intended to complement, not replace, electronic filing and virtual court administration. That positioning is a design goal, not evidence of integration or institutional approval. Any claim about existing systems, staff practice, pilot permission, or data access should be supported by current documentation before external use.

Earlier project notes describe review by a Deputy Chief Registrar and a proposal route to the Chief Registrar. Those institutional assertions were not independently verified during this code review; retain them in external material only after confirming current written evidence. A review or proposal is not itself authorization to use live court data or deploy the prototype.

COURTLOG is being prepared for the Public Sector / e-Governance track. Any Best AI Innovation submission should identify the model as synthetic-data prototyping, not validated predictive performance.
