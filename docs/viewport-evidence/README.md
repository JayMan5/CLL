## Reproduce

From the repository root, install the Playwright browser once, then run the viewport test:

```bash
npx playwright install chromium
npm run test:viewport
```

The test writes fresh local outputs to the ignored `.local/viewport-pass/` directory. Copy the PNGs and `measurements.json` here when refreshing committed evidence. The test verifies page-wide horizontal overflow, worklist/header bounds, table containment, mobile navigation open/close, the registration form at phone/tablet sizes, and the custody-alert filter using mock data only.

This check does not replace real-device, PWA installation, camera/printer, accessibility, cross-browser, or 200% zoom acceptance.
