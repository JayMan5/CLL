# Viewport regression evidence

These screenshots were generated by [`tests/viewport_smoke.cjs`](../../tests/viewport_smoke.cjs) and [`tests/login_viewport_smoke.cjs`](../../tests/login_viewport_smoke.cjs) using headless Chromium and entirely fictional API responses. They are visual regression evidence, not photos from a real device, production environment, court file, or Meta/WhatsApp delivery.

## Reproduce

From the repository root, install the Playwright browser once, then run the viewport test:

```bash
npx playwright install chromium
npm run test:viewport
```

`npm run test:viewport` runs both the login and dashboard suites; `npm run test:viewport:login` runs only the login suite. Fresh outputs go to ignored `.local/viewport-pass/`. Copy the PNGs and both measurement JSON files here when refreshing committed evidence. The login suite checks overlay/card/field/button bounds and label associations. The dashboard suite verifies page-wide horizontal overflow, worklist/header bounds, table containment, mobile navigation open/close, the registration form at phone/tablet sizes, and the custody-alert filter. Both use mocked, fictional data only.

This check does not replace real-device, PWA installation, camera/printer, accessibility, cross-browser, or 200% zoom acceptance.
